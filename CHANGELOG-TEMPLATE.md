# Журнал изменений шаблона 1c-project-template

Журнал для проектов, которые берут правила, навыки и скрипты из шаблона через `/updaterules` (`tools/update-from-template.sh` / `.ps1`). Проект забирает обновления сам; шаблон отвечает за совместимость и за то, чтобы здесь было написано, что проекту делать.

Как вести журнал:

1. Каждый PR в шаблон добавляет строку в раздел с датой слияния (новые даты сверху). Строка одна, начинается с `- `, в конце — номер PR.
2. Пометка `[несовместимо]` — проекту нужно действие (переименование, новый обязательный ключ, другой порядок работы, ломается инструмент или прежний вызов). Пометка `[безопасность]` — закрыта утечка секретов, исполнение чужого кода или риск для данных. После пометки в той же строке — «Проекту: …», что именно сделать.
3. Несовместимое изменение вводится с переходным периодом: старое имя, ключ или вызов продолжает работать с предупреждением, пока проекты не перейдут; срок перехода — в строке журнала.
4. Мажорная версия протокола метаданных синхронизации (`template-sync/<мажор>.<минор>` в `.rules-template-sync.json`) повышается только при несовместимой смене формата; скрипт синхронизации предупреждает о несовпадении.

`tools/update-from-template.sh --check` показывает отставание проекта и строки этого журнала с пометками, появившиеся после версии проекта. Регламент — `docs/headless-agent.md`, раздел «Обновление правил из шаблона».
