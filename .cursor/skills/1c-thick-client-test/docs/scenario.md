# Сценарий

UTF-8 JSON, объект с массивом `steps`. Имена документов, макетов, отчётов и заголовков задаёт сценарий, не код навыка.

## `print`

Печатает документ или подчинённый счёт-фактуру.

- `metadata` — `Документ.Имя` (обязательно)
- `number` — номер документа. `@latest` — последний по дате; вместе с `"posted": true` только проведённый. Выбранный номер пишется в результат шага. Пустой `layout` — первая печатная форма объекта
- `layout` — ключ или заголовок макета из `ПолучитьСтруктуруПечатныхФорм`
- `invoice` — истина: печатать подчинённый `СчетФактураВыданный`, найденный `УчетНДС.НайтиПодчиненныйСчетФактуру`
- `method` — имя экспортного метода объекта. `target`: `manager`, если метод у менеджера
- `args` — массив аргументов. Строка, число или объект:
  - `{"source":"layout"}` — ключ макета
  - `{"source":"attribute","name":"Имя"}` — реквизит объекта
  - `{"source":"collector"}` — пустой массив. Процедура вызывается через `Выполнить`, и если она добавила в массив `ТабличныйДокумент`, шаг забирает его. Так устроена `Печать` УТ 10.3: третий параметр-массив заставляет `НапечататьДокумент` вызвать `Напечатать()` и положить табличный документ в массив. На машине без принтера вызов вернулся и PDF записан самим шагом. На машине с принтером конфигурация отправит лист на принтер
  - `{"procedure":"Имя","count":1|2,"parameter":0,"assign":["Реквизит"]}` — вызвать экспортную процедуру с одним или двумя параметрами, вернуть параметр `parameter`. `assign` дописывает реквизиты объекта в структуру
- `print_form` — имя общей формы. Запасной путь после `Печать`: читает реквизит `ПечатныйДокумент`, только если высота таблицы больше нуля
- `expect_text` — массив подстрок, которые должны быть в `.txt`

Если `method` не задан, шаг пробует экспортные методы `Печать<ключ>` и `<ключ>` у объекта и менеджера без аргументов. Метод, которого нет, пропускается. Метод, который есть и падает, не прячется за формой. Иначе запасной путь: внешняя печатная форма, затем `Печать` и форма. В результате шага `print_path`: `method`, `external`, `print_form` или `form`. В обычном приложении `ПолучитьОкна()` возвращает `Неопределено`, поэтому путь `form` файл обычно не сохраняет.

## `report`

- `metadata` — `Отчет.Имя`. `Отчет.@first` — отчёт, в имени которого есть «Товар» и «Склад», иначе первый отчёт конфигурации. Имя пишется в результат шага
- `date_from`, `date_to` — `ГГГГ-ММ-ДД`, пишутся в `УниверсальныйОтчет`, если реквизит есть, после `УстановитьНачальныеНастройки`
- `settings` — объект имя→значение
- `variant` — не применяется: шаг завершается ошибкой, а не молчаливым пропуском
- `expect_text`

Объектный вызов — `СформироватьОтчет(ТабличныйДокумент)`. На открытой форме — `ОбновитьОтчет()`.

## `open_form`

- `kind` — `object` (по умолчанию), `list`, `report`, `main`
- `metadata`, `number`, `form`
- `generate` — для отчёта вызвать `ОбновитьОтчет()` на форме
- `date_from`, `date_to`

Снимок делает обёртка по маркеру. Форму после снимка закрывает исполнитель.

## `wait`

- `seconds` — целое число секунд
