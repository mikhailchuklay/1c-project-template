# Паттерны проекта

Решения, которые проект уже нашёл и проверил. Архитектор ссылается на пункты в промпте задачи вместо того, чтобы заново формулировать запреты (`docs/headless-agent.md`, «Что положить в промпт запуска»). Файл принадлежит проекту: `/updaterules` создаёт его только если его нет и не перезаписывает.

Как вести:

1. Пункт добавляет архитектор задачи при её закрытии, если решение пригодится следующим задачам: что делаем, как именно (объект, файл, приём), почему не иначе, повод (задача, дата).
2. Пункт, который перестал быть верным, правится или удаляется тем же PR, что меняет поведение.
3. Промпт, который противоречит пункту, исправляется до запуска агента.
